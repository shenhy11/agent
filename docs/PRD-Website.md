## 1. 项目背景

ChronoTech 是一家专注于智能电子手表和可穿戴设备的科技公司。为提升品牌形象与客户体验，需建设一个现代化的企业官网，集产品展示、品牌宣传、智能客服于一体。

### 1.1 项目目标
- 打造高端、科技感强的品牌官网，提升品牌认知度
- 通过精美的产品展示页促进用户了解和购买意愿
- 集成 AI 智能客服，提供 7x24 小时在线咨询
- 支持 PC 和移动端的响应式访问

### 1.2 目标用户
| 角色 | 描述 | 核心需求 |
|------|------|----------|
| **普通消费者** | 浏览产品、了解品牌的潜在客户 | 查看产品详情、规格对比、价格 |
| **科技爱好者** | 关注产品技术参数和评测 | 深度技术规格、产品特色 |
| **售前咨询用户** | 有购买意向但有疑问 | 在线咨询、快速获得解答 |
| **企业采购人员** | 批量采购需求 | 联系方式、企业合作信息 |

## 6. 技术方案概述

### 6.1 前端
- **框架**: HTML + CSS + JavaScript（纯前端，无框架依赖）
- **样式**: Vanilla CSS（CSS 变量 + Grid/Flexbox）
- **动画**: CSS Animations + Intersection Observer API
- **客服组件**: 原生 JavaScript + EventSource (SSE)

### 6.2 后端（已有）
- **框架**: Spring Boot 3.4 + Spring AI 1.0
- **AI 模型**: 通义千问 (DashScope)
- **对话**: ChatClient + MessageWindowChatMemory
- **工具**: @Tool 注解的业务方法

### 6.3 前后端交互
| 接口 | 方法 | 说明 |
|------|------|------|
| `POST /api/chat` | 同步 | 发送消息，等待完整回复 |
| `POST /api/chat/stream` | SSE | 流式对话，打字机效果 |
| `GET /api/products` | 同步 | 获取产品列表 [新增] |
| `GET /api/products/{id}` | 同步 | 获取产品详情 [新增] |
| `POST /api/contact` | 同步 | 提交联系表单 [新增] |
